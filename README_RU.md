# STRIKE ZONE: MOBILE — Unity

Мобильный 3D FPS с офлайн-ботами. Проект отдельный и не связан с Dolbagram.

## Важно
Это стартовая версия проекта. Сцена создаётся редакторским скриптом при открытии проекта в Unity Editor. В этой среде я не могу запустить Unity, поэтому первую облачную сборку нужно считать проверочной: возможные ошибки будем исправлять по логам.

## Рекомендуемая версия
Unity 2022.3 LTS с модулем Android Build Support, Android SDK & NDK Tools и OpenJDK.

## Как это работает
- `Assets/Editor/ProjectSetup.cs` создаёт сцену Main автоматически.
- `Assets/Scripts/GameBootstrap.cs` создаёт тестовую арену, игрока, оружие, ботов и простое меню прямо в игре.
- Управление: WASD/стрелки и мышь в редакторе; на телефоне — виртуальный левый стик и кнопки поворота/стрельбы.

## Следующие этапы
1. Подключить репозиторий к Unity Build Automation.
2. Собрать Android APK.
3. Установить APK на телефон и проверить управление/FPS.
4. После проверки заменить процедурные прототипы на полноценные low-poly модели и добавить карту/арсенал.

Цель производительности: стабильные 30 FPS на начальном уровне, затем оптимизация для 60 FPS на подходящих устройствах.
